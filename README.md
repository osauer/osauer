Personal side projects for learning, trading, and fun. Stuff I think is worth to share is made public and open source.

Everything here is personal work, built and run in my own time. None of it is connected to, sponsored by, or a product of my employer, and nothing here is investment advice.

The current pieces live at [osauer.dev](https://osauer.dev/): [Desk](https://osauer.dev/desk/), a private trading and risk desk, and the parts it stands on: [Torok](https://osauer.dev/torok/) (Go agent harness, private), [Canary](https://github.com/osauer/canary) (local broker desk, open source, runs with Interactive Brokers today), [HyperServe](https://github.com/osauer/hyperserve) (Go HTTP server library, open source) and [Tower](https://osauer.dev/tower/) (experimental, private).
